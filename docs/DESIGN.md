# AFK IDE 설계 문서

원문 설계 기준: https://files.instinct.com/5251b3exqdp7-afk-ide

정통 판타지 방치형 RPG. 아래 수치와 수식은 초기 밸런스 초안입니다. v1은 핵심 루프와 1차 전직까지, 이후 계획은 문서 말미 로드맵을 따릅니다.


## 한 줄 요약

VSCode처럼 생긴 화면 안에서, 진지한 정통 판타지 세계의 영웅이 스스로 모험하는 방치형 RPG.
플레이어는 대부분 지켜보기만 합니다. 정지 버튼을 누르면 장비, 기술, 퀘스트 방향 같은 설정을 손볼 수 있고, 실행 버튼을 누르면 다시 완전 자동으로 돌아갑니다.

## 확정 사양

- **제목**: AFK IDE
- **장르**: Progress Quest 스타일 방치형 RPG
- **겉모습**: VSCode 같은 IDE 레이아웃
- **세계관**: 정통 판타지. 유머 없이 진지하게
- **진행**: 무한 지역 + 환생·유물 + 도감 + 업적·칭호 + 무한의 탑
- **직업**: 4종, 3차 전직까지 (v1은 1차까지)
- **사운드**: 무음
- **저장**: 브라우저 자동저장 + 암호화 파일
- **플랫폼**: 웹 (모바일 우선, 데스크톱 지원)

## 계속하는 이유

- **이번 모험**: 더 높은 지역과 더 좋은 장비를 향해 자동으로 성장합니다.
- **여러 번의 모험**: v1.1에서 환생할 때마다 영구 유물을 쌓고, 도감과 업적을 이어 갑니다. 초기화는 후퇴가 아니라 다음 여정의 준비입니다.
- **나만의 기록**: v1.2 무한의 탑에서 최고 층수를 갱신합니다. 지역 성장, 수집, 도전 중 다음 목표를 고를 수 있습니다.
네 장기 동기 시스템의 도입은 확정입니다. 해금 조건, 보너스, 확률과 버전별 세부 범위는 플레이 테스트용 설계 초안입니다.

## 디자인 원칙

- 비개발자도 즐길 수 있어야 합니다. 화면은 IDE처럼 보여도 용어는 몬스터, 퀘스트, 장비, 기술 같은 실제 RPG 용어만 씁니다. 코드 용어(함수, 커밋, 디버그 등)는 쓰지 않습니다.
- IDE는 틀일 뿐입니다. 탭, 파일 트리, 터미널, 상태바의 모양만 빌리고, 안에 담기는 내용은 전부 판타지입니다.
- 실행과 정지가 방치와 개입을 가릅니다. 실행 중에는 사용자가 손댈 곳이 없고, 정지해야만 설정이 열립니다.
- 반복 설정에는 위임 체크박스를 둡니다. 환생처럼 진행을 초기화하는 결정은 전체 위임에 포함하지 않고 별도로 확인합니다.
- 엔드리스입니다. 엔딩이 없고, 끝이 없는 지역과 성장이 계속됩니다.
이 문서는 개발 지시서를 겸합니다. 값과 수식은 v1 초기값이며 밸런싱 단계에서 조정합니다.

## 화면 구조

VSCode의 5개 영역을 그대로 가져옵니다. 영역 이름은 게임식으로 바꿔 부릅니다.
- **왼쪽 사이드바: 영웅 정보**: 이름과 장착 칭호, 직업, 레벨, 환생 횟수·영구 유물 요약, 경험치 바, HP/MP, 스탯(힘·민첩·지능·체력·행운), 착용 장비 슬롯, 활성 기술 목록. 파일 트리처럼 접고 펼 수 있습니다.
- **중앙 에디터: 모험 로그**: 서사 문장이 쌓이는 큰 영역. '안개 낀 숲에 들어섰다', '고블린 척후병과 마주쳤다' 같은 이야기체 로그. 탭으로 '모험', '퀘스트 일지', '기록'을 전환합니다. v1.1 기록 안에는 몬스터 도감·장비 수집첩·업적·칭호가, v1.2에는 탑 기록이 열립니다.
- **아래 터미널: 전투 로그**: 한 줄씩 짧게 찍히는 전투 기록. '영웅의 베기 → 고블린 -42', '치명타!', '고블린이 쓰러졌다 (+18 EXP)'. 최근 200줄만 유지합니다.
- **하단 상태바**: 왼쪽: 현재 퀘스트와 진행도. 가운데: 현재 지역과 레벨대. 오른쪽: 실행/정지 상태 표시와 실행·정지 버튼.
- **인벤토리 미리보기**: 사이드바 하단 또는 에디터 위 한 줄. 가방 칸 수(예: 23/40), 골드, 최근 획득 아이템 5개를 보여줍니다. 누르면 전체 가방이 열립니다 (정지 중에만 조작 가능).

## 모바일 배치

모바일이 기본입니다. 4개 영역을 한 화면에 욱여넣지 않고 하단 탭으로 나눕니다.
- v1 하단 탭: 영웅 | 모험 | 전투 | 가방. v1.1부터 전투는 모험의 펼침 패널로 합치고 영웅 | 모험 | 가방 | 기록을 씁니다. 기록 안에서 도감·장비·업적·칭호를 전환합니다. 기본은 모험입니다.
- 상태바는 항상 화면 맨 아래에 고정됩니다. 실행/정지 버튼은 엄지가 닿는 오른쪽에 둡니다.
- 터미널(전투 로그)은 "모험" 탭 아래쪽에 두 줄만 미리 보이고, 위로 끌어올리면 전체가 열립니다.
- 768px 이상에서는 데스크톱 IDE 레이아웃으로 바뀝니다: 사이드바 | 에디터 + 터미널 | 상태바.

## 장기 목표의 화면 연결

- v1.1 영웅 화면: 이름 옆 칭호, 환생 횟수, 영구 유물 목록. 기록 화면: 전체/미발견/완료 필터, 등급·세트별 수집률, 다음 해금까지의 처치 수.
- 현재 목표 한 개를 모험 상단에 표시합니다. 예: 안개 숲 희귀종 0/1, 늑대 37/100, 다음 업적 82/100. 기록 열람과 필터는 실행 중에도 가능하며 목표·칭호 변경은 정지 후 적용합니다.
- v1.2 기록에 탑 항목을 추가합니다. 현재 모험 최고 층, 영구 최고 층, 다음 10층 보상과 최근 패배 이유를 보여줍니다. 입장·재도전은 개입 화면에서 정합니다.
- 해금 전 메뉴는 버전 도입 후에만 나타납니다. 조건 미달 항목은 해금 조건을 표시하고, 진행 배지는 색뿐 아니라 숫자와 글자로 구분합니다.

## 비주얼 톤

- 어두운 테마 기본. 배경은 먹색, 강조는 바랜 금색과 짙은 붉은색, 로그 텍스트는 양피지색.
- 탭, 파일 트리 아이콘은 검, 방패, 두루마리, 포션 같은 판타지 아이콘으로 교체합니다.
- 폰트: 본문은 가독성 좋은 산세리프, 제목과 지역명만 세리프 장식체를 씁니다.
- 이모지는 쓰지 않습니다. 아이콘은 SVG로 통일합니다.
- 애니메이션은 최소화합니다. 경험치 바 채움, 로그 한 줄씩 등장, 피격 시 짧은 깜빡임 정도입니다.
터치 영역은 최소 44px. 로그는 자동 스크롤하되, 사용자가 위로 스크롤해 읽는 중이면 자동 스크롤을 멈추고 "맨 아래로" 버튼을 보여줍니다.

## 핵심 루프

실행 중에는 아래 순환이 사람 손 없이 계속 돕니다. 한 사이클은 대략 20~60초를 목표로 합니다.
- 출발: 현재 지역에서 탐험을 시작합니다.
- 조우: 몬스터를 만나거나 랜덤 이벤트가 발생합니다.
- 전투: 턴제로 자동 진행됩니다. 이긴 쪽이 정해질 때까지.
- 전리품: 경험치, 골드, 아이템을 얻습니다. 자동 장착 규칙에 맞으면 바로 교체합니다.
- 퀘스트 갱신: 진행도를 올리고, 완료되면 보상을 받고 다음 퀘스트를 자동 수락합니다.
- 가방 확인: 가방이 가득 차거나(기본 90%), 포션이 바닥나면 마을로 귀환합니다.
- 마을: 판매, 수리, 휴식(HP/MP 회복), 포션 구입을 자동 처리하고 재출발합니다.

## 장기 성장 루프

- 전투 결과를 확정하면 처치·획득 이벤트를 한 번 기록합니다. 도감, 수집첩, 업적이 같은 이벤트를 받아 자동 갱신됩니다.
- 성장이 느려지면 수집 목표를 바꾸거나 더 높은 지역을 노립니다. v1.2부터는 탑 도전으로 전투 구성을 시험합니다.
- 환생 조건을 채우면 알림만 표시합니다. 자동 정지·초기화하지 않으며, 계속 진행할 수도 있습니다.
- 정지 → 환생 미리보기 → 초기화 항목 확인 → 실행으로 영구 유물 1개를 얻고 Lv1에서 재출발합니다. 도감·업적·칭호·탑 최고 기록은 남습니다.
지역 모험과 탑 도전은 동시에 돌지 않습니다. 탑에서도 실행/정지 규칙을 그대로 쓰며, 처치·수집·업적 진척은 중복 없이 반영합니다.

## 랜덤 이벤트

조우 단계에서 약 12% 확률로 일반 몬스터 대신 이벤트가 나옵니다. 위험 허용도 설정이 결과에 영향을 줍니다.
- **보물상자** · 4%: 열면 좋은 아이템. 잠겨 있으면 도적 직업이 유리합니다.
- **함정** · 3%: HP 손실. 민첩이 높으면 회피합니다.
- **떠돌이 상인** · 3%: 마을 밖에서 포션과 장비를 팝니다. 구매 규칙은 마을 행동 설정을 따릅니다.
- **희귀 몬스터** · 2%: 강하지만 보상이 크고 희귀 아이템을 드랍합니다. 위험 허용도가 낮으면 도망칩니다.

## 자동 퀘스트

- 퀘스트는 4종류: 토벌(몬스터 N마리), 수집(아이템 N개), 호위/탐험(지역 지점 도달), 보스(지역 우두머리).
- 완료 시 다음 퀘스트를 자동 수락합니다. 선택은 "퀘스트 방향" 설정을 따릅니다.
- 퀘스트는 지역 레벨대에 맞춰 템플릿에서 생성합니다. 이름과 문장은 진지한 정통 판타지 톤 문장 조합으로 만듭니다.

## 실행/정지 상태 전이

- **실행**: 루프가 도는 중. 설정 패널은 잠김(회색). 로그만 보임.
- **정지 요청**: 버튼을 누르면 "현재 전투가 끝나면 정지" 표시. 전투 중간에 끊지 않습니다.
- **정지**: 루프 멈춤. 개입 화면 활성화. 가방, 장비 변경 가능.
- **재개**: 실행 버튼을 누르면 변경된 설정이 즉시 반영되어 루프 재개.

### A. 장비 설정
장비 교체, 자동 장착 규칙, 강화 우선순위
- 수동 교체: 가방의 장비를 눌러 장착. 비교 화면에서 능력치 증감을 색으로 표시합니다.
- 자동 장착 규칙: 기준을 하나 고릅니다. 공격력 우선 / 방어력 우선 / 균형 / 직업 추천 스탯 우선. 새 장비가 기준 점수보다 높으면 교체합니다.
- 강화 우선순위: 강화 재료를 어느 슬롯부터 쓸지 순서 지정 (무기 > 방어구 > 장신구 등 드래그로 정렬).
- 잠금: 아이템별 "판매 금지" 잠금. 자동 판매에서 제외됩니다.

### B. 기술 설정
기술 슬롯, 사용 조건
- 슬롯: 활성 기술 슬롯 4개 (레벨 30, 60에 슬롯 추가 예정). 습득한 기술을 슬롯에 배치합니다.
- 사용 조건: 슬롯마다 한 가지 조건을 고릅니다. 항상 / HP 50% 이하일 때 / MP 충분할 때 / 적이 보스일 때 / 첫 턴에만.
- 우선순위: 위 슬롯부터 조건이 맞는 첫 기술을 씁니다.

### C. 퀘스트 방향
사냥 / 퀘스트 / 수집 / 안전
- 사냥: 경험치 효율이 높은 몬스터를 우선 찾습니다.
- 퀘스트: 퀘스트 완료 보상을 우선합니다.
- 수집: 아이템 드랍 확률 높은 구역을 우선합니다.
- 안전: 강한 적, 이벤트를 피하고 HP를 넉넉히 유지하며 천천히 진행합니다.

### D. 스탯 분배
레벨업 포인트 분배
- 레벨업마다 5포인트. 힘, 민첩, 지능, 체력, 행운 중에 직접 배분합니다.
- 자동 비율 프리셋: 직업별 추천 비율(예: 전사 힘 40/체력 35/민첩 15/행운 10)을 저장해 두고 레벨업 때 자동 적용합니다.

### E. 포션·소비품 규칙
언제 얼마나 쓰고 살지
- HP 포션 사용 임계값(기본 40%), MP 포션 임계값(기본 25%).
- 마을에서 보유 목표 수량(예: HP 포션 20개). 골드가 모자라면 HP 포션 우선입니다.
- 해독제 등 상태이상 소비품은 "걸리면 즉시 사용" 옵션 제공.

### F. 마을 행동 설정
판매 기준, 수리, 휴식
- 판매 기준: 등급 이하 전부 판매(예: 일반, 고급) / 장착 장비보다 낮은 것만 판매 / 판매 안 함.
- 수리: 내구도가 일정 % 이하면 자동 수리 (골드 소모). 끄면 장비가 망가질 수 있습니다.
- 휴식: 항상 완전 회복 / HP 70%까지만 / 안 쉬기. 휴식은 가상 시간을 소모하지 않고 짧은 대기 연출로 처리합니다.

### G. 위험 허용도
슬라이더 1~5
- 1(신중) ~ 5(과감)의 한 줄 슬라이더. 아래 값들을 한꺼번에 움직입니다.
- 도망 기준 HP, 강한 몬스터 회피 여부, 희귀 몬스터와 함정 이벤트 접근 여부, 지역 이동 속도(안전 1 ~ 도전 5).
- 높을수록 보상과 사망 위험이 모두 커집니다. 사망하면 골드 일부를 잃고 마을에서 부활합니다.

## 개입 화면 (정지 시)

정지 버튼을 누르면 설정 패널이 열립니다. 메뉴는 모바일 기준 2열 카드 격자이고, 카드를 누르면 전체 화면 시트로 열립니다. 실행 중에는 전체가 회색으로 잠기며 "정지하면 설정할 수 있습니다" 안내가 나옵니다.

## 위임 체크박스

반복 설정 A~G 맨 위에 "게임에 맡기기" 체크박스가 있습니다. 설정이 귀찮은 사용자는 체크만 하면 됩니다.
- 메뉴 A~G 각각에 독립된 체크박스가 있고, 기본값은 전부 체크(위임)입니다. 처음 시작하는 사람은 아무것도 만지지 않고 실행만 눌러도 게임이 돌아갑니다.
- 체크하면 그 메뉴의 세부 설정은 회색으로 잠기고 "게임이 알아서 정합니다"가 표시됩니다. 체크를 풀면 마지막 수동값(없으면 기본값)으로 돌아갑니다.
- 위임 상태에서는 게임이 직업과 현재 상황을 보고 값을 정합니다. 수동 설정을 덮어쓰지 않고 별도로 보관합니다.
- 개입 화면 상단에 "전체 위임" 토글을 하나 더 둡니다. 켜면 A~G가 모두 체크됩니다. 개별 메뉴를 풀면 자동으로 꺼집니다.
- H 전직 선택은 위임 대상이 아닙니다. 전직 조건 달성 시 반드시 사용자가 고르거나, 전직 메뉴에서 "추천 경로로 자동 선택"을 직접 눌러야 합니다.

## 위임 시 게임의 자동 판단

- **A 장비**: 직업 추천 스탯 기준 점수로 자동 장착. 강화는 무기, 방어구 순.
- **B 기술**: 직업별 기본 배치표 사용. 공격 기술은 항상, 회복 기술은 HP 50% 이하, 버프는 전투 첫 턴.
- **C 퀘스트 방향**: 레벨이 지역 권장 레벨 이상이면 '퀘스트', 아니면 '사냥'. 사망이 잦으면 '안전'으로 일시 전환.
- **D 스탯**: 직업 추천 비율대로 레벨업 즉시 분배.
- **E 소비품**: HP 40%, MP 25%에서 사용. 마을에서 HP 포션 15개, MP 포션 10개를 목표로 보충.
- **F 마을**: 장착 장비보다 낮은 것만 판매. 내구도 30% 이하면 수리. HP 포션이 있으면 70%까지만 휴식.
- **G 위험 허용도**: 3(보통)에서 시작해 최근 사망 횟수에 따라 2~4 사이를 자동 조정.

## 메뉴 목록 (v1)

- **H. 전직 선택**: 전직 조건 달성 시 활성화. 그 전에는 잠금 표시와 조건 안내. 위임 체크박스 없음.
- **I. 목표 설정, J. 로그 필터**: 이후 업데이트. v1에서는 메뉴 자리를 만들지 않습니다.

## H. 전직 선택

- 1차 전직 조건: 레벨 30 도달 + 전직 퀘스트 1건 완료 (자동 퀘스트 목록에 "시련" 퀘스트로 등장).
- 조건을 달성하면 상태바에 "전직 가능" 알림이 뜨고 실행이 자동 정지됩니다. 사용자가 고를 때까지 H 메뉴가 열려 있습니다.
- 경로 카드에는 새 기술 3개 미리보기, 스탯 보정, 이야기체 설명이 들어갑니다.

## 장기 동기 메뉴 (v1.1부터)

- **K. 환생·영구 유물 (v1.1)**: 정지 상태에서만 환생을 실행합니다. 조건, 예상 유물, 초기화/유지 목록을 먼저 보여준 뒤 별도 확인합니다. 전체 위임이나 전직 자동 선택으로 환생하지 않습니다. 유물 보너스는 자동 적용하므로 관리 설정은 필요 없습니다.
- **L. 수집 목표 (v1.1)**: 도감·장비·지역 희귀종 중 목표 한 개를 고릅니다. 위임 기본 켜짐: 현재 갈 수 있는 안전한 지역의 미완료 목표를 추천하고 추적합니다. 목표는 필수가 아니며 수집 방향(C)을 직접 바꾸지 않습니다. C가 수집일 때만 목표 지역을 우선합니다.
- **M. 칭호 (v1.1)**: 획득 칭호 미리보기와 장착/숨김. 위임 기본 켜짐: 가장 최근 획득 칭호를 표시합니다. 해제하면 마지막 수동 칭호를 복원합니다. 칭호는 외형뿐이라 전투 효율 때문에 바꿀 필요가 없습니다.
- **N. 무한의 탑 (v1.2)**: Lv30 해금. 정지 상태에서 입장·지역 복귀를 선택합니다. 탑 자동 재도전 위임은 기본 꺼짐이며 이 메뉴에서만 켤 수 있습니다. 켜면 3회 연속 패배 시 지역 모험으로 복귀합니다. 꺼져 있으면 첫 패배 후 정지합니다.
전체 위임은 A~G와 도입된 L/M만 켭니다. H 전직, K 환생, N 탑 진입·자동 재도전은 따로 고릅니다. 탑 해금과 환생 가능 알림은 전직 알림과 달리 실행을 강제로 멈추지 않습니다.
모든 변경은 즉시 저장되지만 효과는 "재개"를 누르는 순간부터 적용됩니다. 정지 중에 가방 정리나 장비 교체는 그대로 반영됩니다.

## 직업 구조

기본 직업 4종에서 시작해 최대 3차 전직까지 갑니다. 2차에서 두 갈래로 나뉩니다. v1은 1차 전직까지만 구현합니다.
- **전사**: 높은 체력과 방어. 근접 전투. 주 스탯: 힘, 체력.
- **마법사**: 높은 마법 피해와 MP. 체력이 약함. 주 스탯: 지능.
- **도적**: 빠른 속도, 치명타, 회피, 보물상자와 함정에 강함. 주 스탯: 민첩, 행운.
- **궁수**: 원거리 지속 피해, 첫 턴 선제 공격. 주 스탯: 민첩, 힘.

## 전직 트리

- **조건**: 1차 Lv30, 2차 Lv60, 3차 Lv100. 각 단계마다 시련 퀘스트 1건.
- **구조**: 기본 → 1차(직선) → 2차(2갈래) → 3차(직선)
- **전사**: 1차 나이트 → 2차 팔라딘 / 버서커 → 3차 홀리 나이트 / 워로드 (팔라딘 → 홀리 나이트, 버서커 → 워로드)
- **마법사**: 1차 위저드 → 2차 아크메이지 / 워록 → 3차 대현자 / 네크로맨서
- **도적**: 1차 로그 → 2차 어쌔신 / 섀도우댄서 → 3차 나이트블레이드 / 팬텀
- **궁수**: 1차 레인저 → 2차 스나이퍼 / 비스트마스터 → 3차 윈드로드 / 헌터킹
v1은 1차 전직(나이트, 위저드, 로그, 레인저)까지만 구현합니다. 2·3차 이름은 초안이며 업데이트 때 확정합니다.

## 직업 기본 능력치 (Lv1)

- **전사**: HP 120, MP 20, 힘 8, 민첩 4, 지능 2, 체력 8, 행운 3
- **마법사**: HP 70, MP 80, 힘 2, 민첩 4, 지능 9, 체력 4, 행운 3
- **도적**: HP 85, MP 35, 힘 5, 민첩 9, 지능 3, 체력 5, 행운 6
- **궁수**: HP 90, MP 40, 힘 6, 민첩 8, 지능 3, 체력 5, 행운 4
초기값입니다. 레벨업마다 직업별 기본 성장치 + 자유 분배 5포인트가 붙습니다.

## 환생과 직업

환생 시 네 기본 직업 중 다시 고릅니다. 직업과 전직, 스탯, 기술 숙련은 Lv1 상태로 초기화됩니다. 영구 유물은 직업 공통이며, 직업별 달성 이력과 칭호는 유지합니다. 새 모험의 전직은 기존 H 메뉴 규칙을 그대로 따릅니다.

## 기술

- 직업마다 기본 기술 4개를 Lv1, 5, 10, 20에 습득. 1차 전직 시 새 기술 3개를 얻습니다. 예: 전사 강타, 방패 막기, 도발, 전투의 함성.
- 기술은 MP 소모와 재사용 대기(턴 수)를 가집니다. 기술 설정(B)이 슬롯과 사용 조건을 관리합니다.
- 기술 레벨은 사용 횟수로 오르고 최대 10입니다.

## 전투 시스템

- 턴제 자동 전투. 속도(민첩 기반)가 높은 쪽이 먼저 행동합니다.
- 행동 선택: 기술 설정 우선순위에서 조건이 맞는 첫 기술을, 없으면 기본 공격.
- 피해 = (공격력 × 기술 배율 − 방어력 × 0.5), 최소 1. 변동 ±10%.
- 치명타 확률 = 5% + 행운 × 0.3% + 장비 보정, 치명타 배율 1.5.
- 회피 확률 = 민첩 기반, 최대 40%.
- 위험 허용도 설정에 따라 HP가 도망 기준 아래로 내려가면 전투를 이탈합니다. 이탈하면 보상이 없습니다.
- 사망: 골드 10% 손실, 마을에서 부활, 퀘스트 방향이 "안전"으로 잠시 전환됩니다.

## 성장 시스템

- **필요 경험치**: 레벨 L → L+1에 round(50 × L^1.6)
- **레벨 상한**: 없음. 엔드리스.
- **레벨업 보상**: 직업별 성장치 + 자유 스탯 5포인트
- **기술 숙련**: 사용 횟수 누적, 최대 Lv10

## 몬스터

- 지역마다 테마 몬스터 풀 6~8종 + 우두머리 1종 (예: 안개 숲: 늑대, 고블린 척후병, 늪 트롤, 우두머리 숲의 군주).
- 몬스터 능력치 = 기본값 × 지역 레벨 계수. 지역 레벨 계수는 1.18^(지역 번호).
- 몬스터 이름과 외형 문구는 정통 판타지 톤 사전(고블린, 오크, 언데드, 용족 등)에서 조합합니다.

## 아이템과 장비

- **슬롯**: 무기, 머리, 몸통, 손, 발, 목걸이, 반지 (7칸)
- **등급**: 일반, 고급, 희귀, 영웅, 전설 (색으로 구분)
- **옵션**: 고급 1개, 희귀 2개, 영웅 3개, 전설 3개 + 고유 효과
- **내구도**: 전투마다 감소. 0이면 능력치 절반. 마을에서 수리.
- **강화**: +1 ~ +10. 재료 소모, 실패 시 단계 유지 (파괴 없음)
- **가방**: 기본 40칸. 소비품은 한 칸에 99개까지 겹침.
장비 점수는 직업 추천 스탯에 가중치를 곱한 합으로 계산합니다. 자동 장착과 판매 기준이 이 점수를 씁니다.
- **드랍 확률**: 일반 60%, 고급 28%, 희귀 9%, 영웅 2.5%, 전설 0.5% (지역 번호 10마다 상위 등급 확률 소폭 상승)
- **판매가**: 등급과 아이템 레벨 비례. 마을 상인은 구매가의 40%를 지급.

## 환생·영구 유물 (v1.1 핵심)

아래 수치와 지급 순서는 밸런싱 초안입니다. 영구 보상이 쌓이고 기록이 보존되는 구조는 확정입니다.
- **조건**: 현재 모험 Lv60 이상 + 지역 10 우두머리 최초 격파. 매 모험마다 다시 충족.
- **보상**: 환생 1회당 유물 1개 확정. 확률 보상 없음.
- **지급 순서**: 성장의 불씨 → 강철 인장 → 수호석 → 황금 잎 → 치유의 잔, 이후 반복
- **중복**: 새 가방 칸 대신 같은 유물의 등급 +1. 등급은 누적되며 소모되지 않음.
- 유물 1등급당 성장의 불씨 경험치 +2%, 강철 인장 공격력 +2%, 수호석 최대 HP +2%, 황금 잎 획득 골드 +2%, 치유의 잔 마을 회복량 +2%. 종류별 합산 후 해당 기본값에 한 번 곱합니다. 예: 불씨 3등급이면 경험치 ×1.06. 드랍 확률에는 적용하지 않습니다.
- 초기화: 레벨·경험치·스탯·기술 숙련·전직·골드·장비·가방·퀘스트·지역 개방·이번 모험 탑 진행. 직업을 고르고 기본 장비·포션으로 다시 시작합니다.
- 유지: 영웅 이름, 환생 횟수·유물, 몬스터·장비 도감, 업적·칭호, 누적 통계, 영구 최고 지역과 탑 최고 층. 수동 설정·위임 설정은 보존하되 새 직업에 없는 기술·장비 참조는 기본값으로 바꿉니다.
- 실행은 개입 K에서만 가능합니다. 초기화 목록, 얻을 유물, 다음 직업을 확인한 뒤 확정합니다. 완료 후 정지 상태로 남아 실행 버튼을 기다립니다. 취소하면 아무것도 바뀌지 않습니다.
- 매 회차 낮은 구간을 통과하는 시간과 이전 최고 지역 복귀 시간을 측정합니다. 빠른 초기 재성장은 보장하되 무조건 즉시 환생하는 전략만 유리하지 않게 조정합니다.

## 도감·수집 (v1.1 핵심)

- **몬스터 정보 해금**: 첫 조우: 이름·서식 테마. 누적 처치 1회: 설명·기본 능력. 10회: 약점·사용 기술. 100회: 드랍 후보와 희귀도 정보·완료 표식. 실제 수치는 현재 지역 레벨로 환산해 표시합니다. 도망은 조우만, 처치는 0으로 기록합니다.
- **장비 수집첩**: 직접 획득한 순간 등록합니다. 장착·판매·분해 후에도 유지. 등급별 및 세트별 고유 장비 ID의 수집 수/전체 수와 %를 표시합니다. 세트는 4부위 기준이며 수집 효과는 외형 배지뿐, 착용 세트 효과와 구분합니다.
- **지역 희귀종 목표**: 8개 테마마다 대표 희귀종 1종. 해당 테마 희귀 몬스터 조우 시 풀에서 균등 선택하고, 대표종을 처치하면 수집 완료합니다. 기존 희귀 조우 2%는 그대로 두며 목표 지정이 확률을 올리지는 않습니다. 위험 회피는 수집 목표보다 우선합니다.
- **끝없는 지역과 유한한 수집**: 도감 ID는 생성된 이름·지역 번호가 아닌 몬스터 원형, 장비 원형+등급으로 고정합니다. 새 지역의 같은 원형은 같은 항목에 누적됩니다. 테마 희귀종은 테마 ID+종 ID로 보존합니다. 업데이트로 추가된 항목은 별도 확장 수집률로 표시해 기존 완료 배지를 지키도록 합니다.
수집은 자동 등록이며 보상 수령 버튼을 강요하지 않습니다. 영구 보너스는 환생 유물에 모으고, 도감은 정보 해금·완료 배지·업적 연동을 보상으로 삼습니다. 무한한 신규 항목 때문에 100%가 불가능해지는 구조는 피합니다.

## 업적·칭호 (v1.1 핵심)

- **누적형**: 총 처치 100/1,000/10,000, 환생 1/5/10회, 지역 희귀종 1/4/8종을 초기 단계로 둡니다. 환생 뒤에도 진척이 유지됩니다.
- **도전형**: 이번 모험에서 사망 없이 지역 10 우두머리 격파, 네 기본 직업 각각 1차 전직 달성. 사망 없는 도전의 진행 중 카운터는 환생 때 초기화하지만 획득 업적은 사라지지 않습니다.
- **칭호 예시**: 첫 환생: 돌아온 자. 희귀종 8종: 경계를 살핀 자. 탑 100층: 심연을 걷는 자 (v1.2). 캐릭터 이름 옆 한 개만 표시하며 전투 보너스는 없습니다.
- **지급·알림**: 조건 충족 즉시 한 번만 업적과 칭호를 지급합니다. 미완료/완료 필터와 진척을 보여주며 여러 달성 알림은 한 묶음으로 표시합니다. 누적형과 이번 모험 도전형을 화면에서 구분합니다.

## 무한의 탑 (v1.2)

- **해금·진입**: 현재 모험 Lv30. 개입 N에서 지역 모험 대신 입장. 입장 비용·일일 횟수 제한 없음.
- **진행**: 1층부터 자동 전투. 층 F의 적 능력 = 탑 기본값 × 1.12^(F−1). 10층마다 우두머리(동층 기본값 ×1.5).
- **패배**: 골드 손실 없이 입구에서 회복. 기본은 정지. 자동 재도전 허용 시 재도전하되 연속 3패면 지역 복귀.
- **재진입**: 같은 모험은 마지막으로 깬 층의 다음 층에서 재개. 환생하면 1층부터, 영구 최고 기록은 유지.
- 층 전투의 경험치·골드·장비 보상은 같은 적 전투력의 지역 전투 보상을 기준으로 합니다. 이미 깬 층을 반복 선택하는 기능은 없으며, 패배·도망은 보상이 없습니다.
- 10층 단위 최초 돌파 때 영구 기념 배지를 자동 등록합니다. 마일스톤 ID로 중복 지급을 막습니다. 환생 후 다시 돌파해도 전투 보상만 지급하고 최초 배지는 재지급하지 않습니다. 10/50/100층 업적은 v1.2에 추가합니다.
- 영구 최고 층은 max(기존 최고, 완료한 층)으로만 갱신합니다. 현재 전투 중인 층은 기록으로 인정하지 않습니다. 별도 랭킹이나 시즌 초기화는 없습니다.
- 탑에서는 마을 루프 대신 층 사이 회복·보급을 기존 소비품 규칙과 골드로 처리합니다. 보급할 골드·포션이 없고 안전 조건을 충족하지 못하면 정지하고 지역 복귀를 안내합니다. 정지 요청은 현재 층 전투 종료 후 반영합니다.
- 층수 상한은 두지 않습니다. 전투력은 큰 수 연산으로 계산하고 지수 표기를 지원합니다. Number 오버플로·무한값·저장 정밀도 오류를 테스트합니다.

## 무한 진행 구조

지역은 번호로 이어지는 끝없는 사슬이고, 시드 기반 절차 생성으로 만듭니다.
- 지역 N은 시드 + N으로 이름, 테마, 몬스터 풀, 우두머리를 결정합니다. 같은 시드면 같은 지역이 나옵니다.
- 테마 세트 8종(숲, 늪, 사막, 설산, 동굴, 폐허, 화산, 심연)이 돌아가며 나오고, 이름은 접두어와 접미어 사전에서 조합합니다.
- 지역 우두머리를 쓰러뜨리면 다음 지역이 열립니다. 이전 지역으로 돌아가 사냥하는 선택도 가능합니다 (퀘스트 방향이 자동 선택).
- 권장 레벨은 지역 번호 × 5 근처에서 시작합니다. 지역 번호가 오를수록 몬스터 계수와 드랍 등급이 올라갑니다.
- 수치는 큰 숫자를 안전하게 다루도록 K, M, B 약식 표기를 씁니다.
- 엔딩은 없습니다. 파산 같은 게임 오버도 없습니다. 사망은 페널티만 있고 계속됩니다.

## 저장 시스템

- 자동저장: 30초마다, 그리고 전투 종료, 마을 귀환, 정지 시점에 브라우저 저장소(localStorage, 용량이 크면 IndexedDB)에 저장합니다.
- 슬롯은 1개입니다. 새 캐릭터 시작 시 덮어쓰기 경고를 보여줍니다.
- 내보내기: 설정 > 캐릭터 내보내기 버튼 → "영웅이름.afk" 파일을 내려받습니다.
- 불러오기: .afk 파일을 선택하면 검증 후 현재 저장을 대체합니다. 대체 전에 확인 창을 띄웁니다.

## 장기 기록 저장 구조

- **모험 데이터**: runId, 직업·레벨·장비·스킬, 열린 지역, 현재 퀘스트, 이번 모험 도전 카운터, 탑 현재 층·모험 최고 층·연속 패배 수. 환생 때 기본값으로 재생성합니다.
- **영구 데이터**: 환생 횟수, 유물 ID별 등급, 몬스터 원형별 조우/처치, 획득 장비 ID 집합, 희귀종 완료 집합, 업적 ID와 획득 시각, 칭호 목록·장착 ID, 누적 통계, 최고 지역·탑 층수, 탑 최초 보상 ID 집합.
- **이벤트 중복 방지**: runId+전투 순번으로 결과 이벤트 ID를 만들고 마지막 반영 ID를 저장합니다. 처치, 수집, 업적, 층 돌파 보상을 하나의 결과 적용 단계에서 갱신한 뒤 저장합니다. 새로고침으로 같은 보상을 두 번 받지 않도록 합니다.
- 환생 전 전체 저장 스냅샷을 백업하고, 영구 보상 추가와 새 모험 생성을 한 저장 단위로 확정합니다. 저장 실패 시 기존 모험을 유지하고 완료 알림을 띄우지 않습니다.
- v1 저장 → v1.1: 영구 기록의 기본값을 만듭니다. 과거 처치·획득 이력은 추정하지 않으며 현재 보유 장비만 수집첩에 등록합니다. v1.2: 탑 기록을 0으로 추가합니다. 원본 백업 후 순차 마이그레이션합니다.
- 불러오기는 모험과 영구 기록을 함께 대체합니다. 다른 파일과 병합하지 않습니다. 오래된 파일이면 도감·칭호·최고 기록도 되돌아간다는 확인을 보여줍니다. 영구란 환생 보존을 뜻하며 브라우저 삭제·과거 파일 복원까지 막는다는 뜻은 아닙니다.
- 도감 집합·유물 등급·최고 층·업적 보상 ID도 암호화 및 무결성 검사에 포함합니다. 스키마 검증은 일반 성장과 유물 보정을 구분해 합법적인 영구 보너스를 변조로 오인하지 않게 합니다.

## 암호화와 변조 검사

목표는 일반 사용자가 텍스트 에디터나 개발자 도구로 값을 고칠 수 없게 하는 것입니다. 서버가 없는 웹 게임이므로 아래 방식으로 구현합니다.
- 저장 데이터는 JSON으로 직렬화합니다. 키 순서를 고정(정렬)해 같은 입력이 같은 문자열이 되게 합니다.
- 페이로드에 스키마 버전, 저장 시각, 영웅 레벨 요약, 진행 카운터를 포함합니다.
- 무결성 값: HMAC-SHA-256을 JSON 전체에 대해 계산해 메타에 붙입니다.
- 암호화: Web Crypto API의 AES-256-GCM을 씁니다. 매 저장마다 12바이트 랜덤 IV를 새로 만듭니다. GCM 인증 태그가 변조를 한 번 더 막아 줍니다.
- 키: 게임 빌드에 들어 있는 비밀 값과 파일별 16바이트 솔트를 PBKDF2(SHA-256, 100,000회)로 섞어 만듭니다. 사용자는 비밀번호를 입력하지 않습니다.
- 파일 구조: 매직 바이트 "AFK1" | 버전 1바이트 | 솔트 16바이트 | IV 12바이트 | 암호문+태그. 전체를 Base64로 감싸 .afk 텍스트 파일로 저장합니다.
- 불러오기 순서: 매직/버전 확인 → 복호화(실패 시 "손상되었거나 수정된 파일입니다") → HMAC 비교 → 스키마 검증(값 범위, 아이템 ID 존재 여부) → 적용.
- 범위 검증: 레벨, 골드, 스탯이 해당 진행도에서 나올 수 없는 값이면 거부합니다. 예: 레벨 대비 경험치 총량 불일치.
- 이전 버전 파일은 버전 번호를 보고 마이그레이션 함수를 순서대로 적용합니다.
비밀 값이 브라우저에 실려 가는 구조라서, 코드를 분석할 줄 아는 사람은 우회할 수 있습니다. 서버 없는 방식의 근본적인 한계입니다. 이 게임이 막으려는 대상은 일반 사용자의 에디터 수정입니다. 랭킹이나 경쟁 요소가 생기면 서버 검증이 필요합니다.

## 자동저장 데이터도 암호화

브라우저 저장소에 들어가는 자동저장도 같은 형식으로 암호화합니다. 개발자 도구의 저장소 탭에서도 읽을 수 없어야 하기 때문입니다.

## 기술 구현 가이드

- **형태**: 정적 웹앱. 서버 없음. 단일 페이지 + 모듈 분리.
- **언어**: 바닐라 JS 또는 TypeScript. 프레임워크는 선택 사항.
- **배포**: GitHub Pages
- **루프**: requestAnimationFrame 대신 고정 틱(예: 200ms)의 setInterval. 탭이 백그라운드여도 돌도록 경과 시간 기준으로 보정.
- **난수**: 시드 기반 PRNG (지역 생성용). 전투는 일반 난수.
- **데이터**: 몬스터, 아이템, 기술, 퀘스트 템플릿은 JSON 데이터 파일로 분리.
- 모듈: state(상태), loop(루프), combat(전투), loot(전리품), quest(퀘스트), town(마을), region(지역 생성), delegate(위임 판단), save(저장·암호화), ui(화면). v1.1에 prestige(환생), collection(도감), achievement(업적), v1.2에 tower(탑)를 추가합니다. 데이터 파일은 유물·수집 원형·업적·탑 보상 ID도 관리합니다.
- 위임 판단(delegate)은 설정 값 조회 함수 하나로 묶습니다. 모든 시스템은 "설정을 직접 읽지 않고 이 함수를 거쳐" 값을 얻습니다. 위임이면 자동 값, 아니면 수동값을 돌려줍니다.
- 백그라운드 탭이나 접속을 끈 시간은 오프라인 진행으로 처리하지 않습니다. 열려 있는 동안만 진행합니다. (v1 범위 결정, 추후 논의)

- 새 캐릭터로 시작해 설정을 하나도 건드리지 않고 실행만 눌러도 레벨 30까지 사망 없이 자동으로 진행됩니다.
- 정지하면 A~G 메뉴가 열리고, 실행 중에는 잠깁니다.

- 새로고침 후에도 이어서 진행됩니다.
- 모바일 세로 화면(390px)에서 모든 화면이 가로 스크롤 없이 동작합니다.
- 코드와 화면 텍스트에 개발 용어나 유머 문구가 없습니다.
